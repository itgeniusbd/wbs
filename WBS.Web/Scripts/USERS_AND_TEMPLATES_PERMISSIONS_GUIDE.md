## ?? Verification Queries

### Check if permissions added:
```sql
-- Check Users permissions
SELECT * FROM Permissions WHERE Module = 'Users';

-- Check Notification Templates permissions
SELECT * FROM Permissions WHERE Module = 'Notification Templates';

-- Count total permissions
SELECT COUNT(*) as TotalPermissions FROM Permissions;
```

### Check which roles have these permissions:
```sql
SELECT 
    r.Name as RoleName,
    p.Module,
    p.Action,
    p.Name as PermissionName
FROM AspNetRoles r
INNER JOIN RolePermissions rp ON r.Id = rp.RoleId
INNER JOIN Permissions p ON rp.PermissionId = p.Id
WHERE p.Module IN ('Users', 'Notification Templates')
ORDER BY r.Name, p.Module, p.DisplayOrder;
```
